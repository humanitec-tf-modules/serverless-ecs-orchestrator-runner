# Serverless ECS runner module v4.0.0

This breaking release adopts the HTTPS runner-gateway contract used by runner
`v3.0.0`. The ECS task definition no longer accepts or injects NATS endpoints,
tokens, Secrets Manager parameters, or broker-specific KMS permissions.

The data plane supplies each task with the public runner-gateway URL,
organization and runner identity, and a deployment-scoped token. Existing
per-install OIDC federation remains responsible for AWS authentication and is
unchanged by the transport architecture.

The module passed 12 Terraform and 12 OpenTofu test runs. Its task-definition
and IAM behavior were validated locally; a live ECS task was not executed as
part of this release qualification.
