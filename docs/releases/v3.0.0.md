# Serverless ECS runner module v3.0.0

This breaking release moves runner communications from direct HTTP calls to
NATS and includes the previously unreleased required per-install OIDC hostname
input.

Callers must provide `nats_url` and `nats_token_secret_arn`. The module exposes
the URL to the runner and injects the token from AWS Secrets Manager or SSM.
Use a TLS NATS endpoint reachable from the ECS tasks and issue a subject-scoped
token for each runner installation.

The ECS task execution role receives read access only to the configured Secrets
Manager secret or SSM parameter. Set `nats_token_kms_key_arn` when that value is
encrypted with a customer-managed KMS key; the resulting decrypt permission is
scoped to that exact key.

The module and its use-case integration were validated with Terraform and
OpenTofu. This module covers the simple and intermittently connected edge
paths. It does not implement or qualify the physical diode transport.
